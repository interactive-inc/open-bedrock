# 用語集

[[index|open-karte]]で使う用語の索引。製品固有の機能は[[features|機能一覧]]を参照し、ここでは細かく書かない。

## 用語

- 従業員台帳: 全機能の参照元となる人の事実の記録。人を指す情報をここに一本化する。詳細は[[employee-directory|従業員台帳 CRUD+検索]]
- 申請ワークフロー: 申請から承認、記録までの一連の流れ。各領域に共通する基盤として持つ。詳細は[[approval-workflow|申請ワークフロー基盤]]
- 人・時間・物・お金・成長: [[index|open-karte]]が束ねる事務手続きの5領域。それぞれ従業員台帳を参照して成立する
- セルフホスト: 外部 SaaS に頼らず、自社で基盤を運用すること。データを自分たちで持てることを重視する
- karte コマンド: 引数を api への POST に変換するローカルの CLI。AI から呼ばれることを前提とする
