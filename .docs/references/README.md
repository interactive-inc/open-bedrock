# 制度用語リファレンス

規範性: 根拠記録。外部制度用語の一般的な意味を保存する。

制度用語の一般的な意味を一語一ファイルで記録する非規範領域とする。製品の domain type、導入組織の規程、適用判断、法的判断の根拠に使用しない。

- open-karte の概念は [会社メタモデル](../company-model.md) と [用語集](../glossary.md) を正とする。
- 法令依存の定義、金額、日数、対象者は利用時点の公式 source で再検証する。
- 同じ日本語が複数の制度上の意味を持つ場合は、namespace または文脈を付ける。
- AI は用語説明だけから適用可否を判断せず、対象事実、法域、規程版、外部専門判断を確認する。
