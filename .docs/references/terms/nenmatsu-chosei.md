# 年末調整（ねんまつちょうせい）

規範性: 根拠記録。参照語彙。open-karte 固有概念は会社メタモデルと用語集を優先する。

給与から毎月差し引いてきた [[gensen-shotokuzei|源泉所得税]] の合計と、その年の本来の年税額との差を年末に精算する手続き。給与を支払う [[gensen-choshu-gimusha|源泉徴収義務者]] が行い、差額を還付または追加徴収する。各種の所得控除や [[fuyo|扶養]] の状況をこの段階で反映する。ここで対応できない控除（医療費控除など）がある人や複数収入がある人は、別途 [[kakutei-shinkoku|確定申告]] で精算する。
