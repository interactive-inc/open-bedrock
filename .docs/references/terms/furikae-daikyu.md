# 振替休日と代休（ふりかえきゅうじつとだいきゅう）

どちらも休日に出勤したときの調整だが、時期と扱いが異なる。振替休日は、あらかじめ休日と労働日を入れ替えておく方法で、出勤日が通常の労働日になるため休日労働の割増賃金は発生しない。代休は、休日労働をさせた後に代わりの休みを与える方法で、休日労働の事実は残るため割増賃金の支払いが必要になる。休日労働は [[36-kyotei|36協定]] の対象であり、賃金が支払われる [[nenji-yukyu-kyuka|年次有給休暇]] とは性質が異なる。
