# 仕入税額控除（しいれぜいがくこうじょ）

事業者が納める消費税を計算する際に、売上で預かった消費税から、仕入れや経費で支払った消費税を差し引く仕組み。これにより同じ取引に税が二重にかからないようになっている。控除を受けるには、原則として [[tekikaku-seikyusho|適格請求書]] の保存が要件となり、相手が [[tekikaku-hakko-jigyosha|適格請求書発行事業者]] であることが前提になる。[[menzei-jigyosha|免税事業者]] からの仕入れは [[invoice-seido|インボイス制度]] のもとで控除に制限がかかる。
