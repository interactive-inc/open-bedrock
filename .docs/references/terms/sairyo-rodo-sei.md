# 裁量労働制（さいりょうろうどうせい）

仕事の進め方や時間配分を労働者の裁量に委ね、実際の労働時間ではなく労使であらかじめ定めた時間を働いたものとみなす制度。この「みなし労働時間」を基準に賃金を計算するため、日々の残業時間の集計とは異なる扱いになる。みなし時間が法定労働時間を超える設計では、その分の割増賃金を織り込む必要があり [[minashi-zangyo|みなし残業]] と似た考え方をとる。深夜労働や休日労働の割増は別途発生し、[[36-kyotei|36協定]] の対象になる。専門業務型と企画業務型があり、導入には労使協定や決議が求められる。
