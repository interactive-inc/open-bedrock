# 定期健康診断（ていきけんこうしんだん）

規範性: 根拠記録。参照語彙。open-karte 固有概念は会社メタモデルと用語集を優先する。

労働安全衛生法に基づき、事業者が常時使用する労働者に対して原則年1回実施する義務のある健康診断。身長・体重・血圧・血液検査などの法定項目があり、費用は事業者が負担する。労働者にも受診する義務がある。結果は記録として保存し、所見があった場合は医師の意見を踏まえて就業上の措置を検討する。雇入れ時の健康診断などと並ぶ、職場の健康管理の基礎となる制度。
