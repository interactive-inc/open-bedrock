# 通勤手当（つうきんてあて）

規範性: 根拠記録。参照語彙。open-karte 固有概念は会社メタモデルと用語集を優先する。

労働者が自宅と勤務地の間を通勤するのに要する費用を補助する手当。法律上の支給義務はなく、各事業場が就業規則などで支給基準を定める。公共交通機関や自家用車など通勤手段ごとに一定額までが所得税の非課税限度額として扱われ、それを超える分は課税対象となり [[gensen-shotokuzei|源泉所得税]] の計算に含まれる。社会保険料の算定基礎には含まれる点も実務上の論点になる。
