# 育児休業（いくじきゅうぎょう）

規範性: 根拠記録。参照語彙。open-karte 固有概念は会社メタモデルと用語集を優先する。

原則として1歳に満たない子を養育するために取得できる休業。保育所に入れないなどの事情があれば期間を延長でき、両親がともに取得する場合の特例もある。子の出生直後に父親が柔軟に取得できる枠（産後パパ育休）も別途設けられている。一定の要件を満たすと雇用保険から育児休業給付が支給される。介護を理由とする [[kaigo-kyugyo|介護休業]] と並ぶ、家族のケアのための長期休業制度。
