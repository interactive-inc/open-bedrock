# インボイス制度（いんぼいすせいど）

消費税について、定められた形式の請求書を発行・保存することで売上に対する税から仕入れの税を差し引けるようにする仕組み。正式には適格請求書等保存方式という。買い手が [[shiire-zeigaku-kojo|仕入税額控除]] を受けるには、売り手が発行した [[tekikaku-seikyusho|適格請求書]] の保存が要件となる。適格請求書を出せるのは登録を受けた [[tekikaku-hakko-jigyosha|適格請求書発行事業者]] だけで、[[menzei-jigyosha|免税事業者]] は発行できない。
