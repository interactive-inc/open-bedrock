# フレックスタイム制（ふれっくすたいむせい）

規範性: 根拠記録。参照語彙。open-karte 固有概念は会社メタモデルと用語集を優先する。

一定期間（清算期間）の総労働時間をあらかじめ定め、その範囲内で始業・終業の時刻を労働者自身が決められる制度。必ず勤務すべき時間帯（コアタイム）と、その前後で出退勤を自由に選べる時間帯（フレキシブルタイム）を設けるのが一般的だが、コアタイムを置かない運用もある。残業の有無は日々ではなく清算期間の総労働時間で判断され、超過分は [[36-kyotei|36協定]] の対象となる。導入には労使協定が必要。
