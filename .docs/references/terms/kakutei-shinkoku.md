# 確定申告（かくていしんこく）

規範性: 根拠記録。参照語彙。open-karte 固有概念は会社メタモデルと用語集を優先する。

1年間の所得と納めるべき税額を自分で計算し、税務署へ申告して納税（または還付を受ける）手続き。通常は翌年の決められた期間内に行う。給与所得者でも、[[nenmatsu-chosei|年末調整]] では扱えない医療費控除や寄附金控除を受けたい場合、複数から収入がある場合などに必要になる。すでに差し引かれた [[gensen-shotokuzei|源泉所得税]] や [[fukko-tokubetsu-shotokuzei|復興特別所得税]] は、この申告で精算される。
