# 適格請求書発行事業者（てきかくせいきゅうしょはっこうじぎょうしゃ）

税務署に登録を行い、Tから始まる13桁の登録番号を持つ事業者。この登録があってはじめて [[tekikaku-seikyusho|適格請求書]] を発行でき、取引相手は [[shiire-zeigaku-kojo|仕入税額控除]] を受けられる。登録すると課税事業者として消費税の納税義務が生じるため、[[menzei-jigyosha|免税事業者]] が [[invoice-seido|インボイス制度]] に対応する際は登録するかどうかの判断が必要になる。
