# みなし残業（みなしざんぎょう）

規範性: 根拠記録。参照語彙。open-karte 固有概念は会社メタモデルと用語集を優先する。

あらかじめ一定時間分の時間外労働があったものとみなし、その残業代を固定額として毎月の給与に含めて支払う仕組み。固定残業代とも呼ぶ。何時間分・いくらに相当するかを明示する必要があり、実際の残業がみなし時間を超えた場合は差額を別途支払わなければならない。時間外労働そのものは [[36-kyotei|36協定]] の範囲内で行う必要があり、労働時間を労使で定める [[sairyo-rodo-sei|裁量労働制]] とは別の仕組み。
