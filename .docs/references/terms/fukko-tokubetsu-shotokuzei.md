# 復興特別所得税（ふっこうとくべつしょとくぜい）

規範性: 根拠記録。参照語彙。open-karte 固有概念は会社メタモデルと用語集を優先する。

東日本大震災からの復興財源を確保するため、所得税額に2.1%を上乗せして課される税。所得税とあわせて納める仕組みになっている。報酬・料金等を支払うときの源泉徴収では、所得税10%にこの上乗せが加わり合計10.21%が差し引かれる。実際の徴収は [[gensen-shotokuzei|源泉所得税]] と一体で行われ、最終的な精算は [[kakutei-shinkoku|確定申告]] による。
