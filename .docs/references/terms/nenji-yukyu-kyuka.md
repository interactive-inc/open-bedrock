# 年次有給休暇（ねんじゆうきゅうきゅうか）

一定期間以上継続して勤務し、所定労働日の一定割合以上を出勤した労働者に付与される、賃金が支払われる休暇。勤続年数や週の所定労働日数に応じて付与日数が増える。年10日以上付与される労働者には、年5日を取得させる使用者の義務がある。労働者が時季を指定して取得でき、原則として理由を問われない。[[kanri-kantokusha|管理監督者]] にも適用され、[[keicho-kyuka|慶弔休暇]] などの特別休暇とは別枠で扱われる。
