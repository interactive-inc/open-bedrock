# 適格請求書（てきかくせいきゅうしょ）

規範性: 根拠記録。参照語彙。open-karte 固有概念は会社メタモデルと用語集を優先する。

登録番号、適用した税率、税率ごとの消費税額などを記載した、定められた様式の請求書。いわゆるインボイスのこと。買い手はこれを保存することで [[shiire-zeigaku-kojo|仕入税額控除]] を受けられる。発行できるのは登録を済ませた [[tekikaku-hakko-jigyosha|適格請求書発行事業者]] に限られ、これが [[invoice-seido|インボイス制度]] の中核となる書類になる。
