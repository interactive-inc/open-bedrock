# 免税事業者（めんぜいじぎょうしゃ）

規範性: 根拠記録。参照語彙。open-karte 固有概念は会社メタモデルと用語集を優先する。

一定の基準期間の課税売上が小さいなどの理由で、消費税の納税義務が免除される事業者。預かった消費税を納めなくてよい一方、[[tekikaku-hakko-jigyosha|適格請求書発行事業者]] の登録ができないため [[tekikaku-seikyusho|適格請求書]] を発行できない。そのため取引相手は [[shiire-zeigaku-kojo|仕入税額控除]] を受けにくくなり、[[invoice-seido|インボイス制度]] への対応として課税事業者になるかを検討する場面が出てくる。
