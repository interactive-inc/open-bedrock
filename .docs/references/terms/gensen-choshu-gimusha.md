# 源泉徴収義務者（げんせんちょうしゅうぎむしゃ）

規範性: 根拠記録。参照語彙。open-karte 固有概念は会社メタモデルと用語集を優先する。

給与や報酬を支払う際に [[gensen-shotokuzei|源泉所得税]] を差し引き、預かった税額を国に納付する義務を負う支払い側のこと。法人や、従業員を雇う個人事業主などが該当する。差し引いた税は原則として翌月までに納付し、給与については年末に [[nenmatsu-chosei|年末調整]] を行って年間の過不足を精算する役割も担う。
