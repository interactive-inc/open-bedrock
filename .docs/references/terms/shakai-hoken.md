# 社会保険（しゃかいほけん）

病気・けが・老齢・失業・労働災害などに備え、保険料を出し合って給付を受ける公的な保険の総称。会社員に関わるのは主に健康保険・厚生年金保険・雇用保険・労災保険で、健康保険と厚生年金は給与から労使折半で天引きされる。入社・退社、扶養の増減、転居、氏名変更などのたびに会社が加入・喪失・変更の手続きを行うため、本人は届出だけで足りることが多い。[[fuyo|扶養]] の認定や [[shussan-ikuji-ichijikin|出産育児一時金]] もこの仕組みの一部で、退職時の資格喪失や任意継続も社会保険に関わる。
