# 電子帳簿保存法（でんしちょうぼほぞんほう）

規範性: 根拠記録。参照語彙。open-karte 固有概念は会社メタモデルと用語集を優先する。

帳簿や請求書などの国税関係の書類を、紙ではなく電子データで保存するための要件を定めた法律。大きく、会計ソフト等で作った帳簿の電子保存、紙の書類を画像で取り込むスキャナ保存、メールやネット取引でやり取りした電子取引データの保存に分かれる。電子取引のデータは原則として電子のまま保存することが求められる。[[keihi-seisan|経費精算]] で受け取る領収書や [[tekikaku-seikyusho|適格請求書]] の扱いにも関わる。
