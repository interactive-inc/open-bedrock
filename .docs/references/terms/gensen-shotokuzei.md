# 源泉所得税（げんせんしょとくぜい）

給与や報酬などを支払う側が、支払いの時点であらかじめ所得税を差し引いて国に納める仕組み。受け取る側が後でまとめて納めるのではなく、支払いのたびに少しずつ前払いされる形になる。差し引いて納める義務を負うのが [[gensen-choshu-gimusha|源泉徴収義務者]] で、報酬・料金等では [[fukko-tokubetsu-shotokuzei|復興特別所得税]] を含めて源泉する。年間の過不足は給与なら [[nenmatsu-chosei|年末調整]]、それ以外は [[kakutei-shinkoku|確定申告]] で精算する。
