# 経費精算（けいひせいさん）

従業員が業務のために自分で立て替えて支払った費用を申請し、会社から払い戻しを受ける手続き。領収書などの証憑をもとに金額と用途を申請し、承認を経て精算される。[[shuccho-ryohi|出張旅費]] のような費用もこの流れで処理されることが多い。受け取った領収書や [[tekikaku-seikyusho|適格請求書]] は [[denshi-chobo-hozonho|電子帳簿保存法]] の要件に沿って保存する必要があり、高額な支出は事前に [[ringi|稟議]] を通すこともある。
