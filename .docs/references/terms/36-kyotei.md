# 36協定（さぶろくきょうてい）

労働基準法36条に基づき、法定労働時間を超える時間外労働や休日労働を行わせるために必要な労使協定。事業場の過半数代表者などと締結し、労働基準監督署へ届け出ることで効力をもつ。延長できる時間には上限が定められ、臨時的な事情があるときは特別条項によってさらに延長できるが、これにも年間の上限がある。[[kanri-kantokusha|管理監督者]] は時間外規定の対象外で、[[minashi-zangyo|みなし残業]] を設ける場合もこの協定の範囲内で運用する。
