# API Schema

ここでは CLI が叩くバックエンド API の構造を記載する。バックエンド本体はこのリポジトリには含まれず、CLI からは FastAPI 製サーバ(既定 http://127.0.0.1:8000)として参照される。

## 認証方式

ログインでトークンを取得し、以降のリクエストは Authorization ヘッダに Bearer トークンを付与する。

## エンドポイント構造

リソースごとにパスが分かれている。CLI から参照されるリソースは認証、社員、申請テンプレート、申請、ナレッジ、会議室、スキル、目標、1on1、アンケート、キャリア、ダッシュボード、バッチ、フィーチャーに対応する。一覧取得は GET、作成や提出や承認などの操作は POST、自分のスキルやキャリアシートの更新は PUT を用いる。

## 注記

- api ワークスペース(Hono on Cloudflare Workers)は現状スキャフォールドで、上記バックエンドとは別物。両者の統合方針は未確認。
- 個別エンドポイントの一覧は実装(コード)を参照する。
