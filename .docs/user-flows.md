# ユーザーフロー

ここでは利用者の主要導線を記載する。同じ業務は karte コマンドと web のどちらからでも実行できる。

## 社員導線

### ログインして自分の情報を確認する

1. メールアドレスとパスワードでログインする
2. トークンが保存される
3. 自分の情報を表示する

### 申請を提出する

1. 申請テンプレートの一覧を確認する
2. 提出したいテンプレートの詳細を確認する
3. 入力データを用意してテンプレートを指定し提出する
4. 自分の申請一覧で状態を確認する

### ナレッジを調べる

1. キーワードやカテゴリでナレッジを検索する
2. 目的のナレッジの詳細を確認する

### 会議室を予約する

1. 期間を指定して空き状況を確認する
2. 空いている会議室を指定して予約する

### スキルや目標を申告する

1. 自分のスキルを確認する
2. スキルを登録または更新する or 目標を作成する
3. 必要に応じて目標の評価を登録する

### キャリアを申告し公募に応募する

1. 自分のキャリアシートを確認する
2. キャリアシートを更新する
3. 社内公募の一覧を確認する
4. 応募したい公募に応募する

## 上長や管理者導線

### 申請を承認または却下する

1. 自分宛の承認待ち一覧を確認する
2. 対象の申請の詳細を確認する
3. 申請を承認する or 却下する

### 組織の状態を把握する

1. ダッシュボードの集計を確認する
2. 必要に応じて社員を検索する
