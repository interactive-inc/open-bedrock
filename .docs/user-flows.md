# ユーザーフロー

実コードは未実装。以下は[[index|方向性]]に基づく想定導線であり、実装が進んだらコードを正として更新する。最初に固めるのは[[employee-directory|従業員台帳 CRUD+検索]]の導線。

## 運用担当導線

### 従業員の登録

1. 従業員の新規登録を開く
2. 氏名や所属など台帳の項目を入力して登録する
3. 従業員一覧で登録結果を確認する

### 従業員の検索

1. 従業員一覧を開く
2. キーワードや部署、在籍状況で絞り込む
3. 該当者の詳細を確認する

## 社員導線

### 申請の提出

1. 申請の種類を選ぶ
2. 申請内容を入力して提出する
3. 自分の申請一覧で状態を確認する

## 上長導線

### 承認

1. 承認待ち一覧を開く
2. 申請の詳細を確認する
3. 承認 or 却下を選ぶ
4. コメントを添えて確定する
