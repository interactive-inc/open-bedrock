# 操作フロー

API、CLI、Web の提供範囲は一致を前提としない。操作はコードの route と入出力、[認可モデル](./authorization-model.md) の認可、[製品目的と境界](./product-purpose.md) の責任境界に従う。自社の正式手続きまたは将来計画を操作フローから推定しない。

## 社員導線

### ログインして自分の情報を確認する

1. メールアドレスとパスワードでログインする
2. トークンが保存される
3. 自分の情報を表示する

### 申請を提出する

1. 申請テンプレートの一覧を確認する
2. 提出したいテンプレートの詳細を確認する
3. 入力データを用意してテンプレートを指定し提出する
4. 自分の申請一覧で状態を確認する

### ナレッジを調べる

1. キーワードやカテゴリでナレッジを検索する
2. 目的のナレッジの詳細を確認する

### 規程・手続きを運用する

1. 自社の非公開 source で版、対象、責任、ProcedureDefinition、公開 review を定義する
2. `karte governance sync` で draft を同期し、参照、role assignment、期限、rule overlap 候補を検査する
3. 公開 review が必要な版は権限ある人間が review し、公開権限者が承認済み content hash を publish する
4. 現行実装では published status と audience が一致する文書を従業員が閲覧し、必要な文書は acknowledgement を記録する
5. 現行実装は施行期間による表示制御、合議体 quorum、review candidate snapshot を持たないため、それらを必要とする正式運用には使わない

### 会議室を予約する

1. 期間を指定して空き状況を確認する
2. 空いている会議室を指定して予約する

### スキルや目標を申告する

1. 自分のスキルを確認する
2. スキルを登録または更新する、または目標を作成する
3. 必要に応じて目標の評価を登録する

### キャリアを申告し公募に応募する

1. 自分のキャリアシートを確認する
2. キャリアシートを更新する
3. 社内公募の一覧を確認する
4. 応募したい公募に応募する

### 出退勤を打刻する

1. 出勤を打刻する
2. 退勤を打刻する
3. 自分の勤怠と月次サマリを確認する

### 経費を申請する

1. カテゴリと金額を指定して経費を申請する
2. 自分の経費の一覧で状態を確認する

### 感謝を送り報酬と交換する

1. 同僚を指定して感謝メッセージを送る
2. 自分の残ポイントと受け取った感謝を確認する
3. 交換カタログから報酬を選び交換を申請する

### シフト交代を申請する

1. 自分のシフトを確認する
2. 交代相手と対象日を指定して交代を申請する

### 通知を確認する

1. 自分宛の通知と未読数を確認する
2. 通知を個別または一括で既読にする

## 上長や管理者導線

### 人事変更を申請または確定する

1. 従業員詳細で現在の所属、役職、直属上司と人材タイムラインを確認する
2. 変更種別と発令日を指定する
3. マネージャーは組織範囲内の変更を承認フローへ申請する
4. 人事権限を持つ担当者は直接確定するか、申請の最終承認で発令を確定する
5. 入社または退職の場合は、設定済みテンプレートのオンボーディングタスクをバッチで展開する

### 申請を承認または却下する

1. 自分宛の承認待ち一覧を確認する
2. 対象の申請の詳細を確認する
3. 申請を承認する、または却下する
4. 差戻しの場合は申請者が内容を修正して再申請する

### 承認フローを設定する

1. `application_template:manage` 権限を持つ担当者が申請テンプレートの承認フロー設定を開く
2. 組織上の上司、IAM ロール、従業員指定から承認者を選ぶ
3. 多段、全員または必要人数、条件、期限、差戻し、代理承認可否を設定する
4. 保存後に提出された申請から新しい定義を適用する

### 承認を委任する

1. 承認者が代理先、対象期間、必要なら対象テンプレートを指定する
2. 期間中は代理先の承認 inbox に対象申請を表示する
3. 承認履歴には操作した代理人と委任元を両方記録する

### 経費を承認または却下する

1. 自分宛の経費の承認待ち一覧を確認する
2. 対象の経費の内容を確認する
3. 経費を承認する、または却下する

### 感謝ポイントの交換を承認または却下する

1. 交換申請の承認待ち一覧を確認する
2. 対象の交換申請を確認する
3. 交換を承認する、または却下する

### 組織の状態を把握する

1. ダッシュボードの集計を確認する
2. 必要に応じて社員を検索する

### ロールを作って権限を絞る

1. 権限カタログを確認する
2. 必要な権限だけを選んでロールを作成する
3. 対象のアカウントにロールを割り当てる
4. 対象者の画面とメニューが権限どおりに絞られる
