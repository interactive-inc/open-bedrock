# ユーザーフロー

ここでは利用者の主要導線を記載する。同じ業務は karte コマンドと web のどちらからでも実行できる。

## 社員導線

### ログインして自分の情報を確認する

1. メールアドレスとパスワードでログインする
2. トークンが保存される
3. 自分の情報を表示する

### 申請を提出する

1. 申請テンプレートの一覧を確認する
2. 提出したいテンプレートの詳細を確認する
3. 入力データを用意してテンプレートを指定し提出する
4. 自分の申請一覧で状態を確認する

### ナレッジを調べる

1. キーワードやカテゴリでナレッジを検索する
2. 目的のナレッジの詳細を確認する

### 会議室を予約する

1. 期間を指定して空き状況を確認する
2. 空いている会議室を指定して予約する

### スキルや目標を申告する

1. 自分のスキルを確認する
2. スキルを登録または更新する or 目標を作成する
3. 必要に応じて目標の評価を登録する

### キャリアを申告し公募に応募する

1. 自分のキャリアシートを確認する
2. キャリアシートを更新する
3. 社内公募の一覧を確認する
4. 応募したい公募に応募する

### 出退勤を打刻する

1. 出勤を打刻する
2. 退勤を打刻する
3. 自分の勤怠と月次サマリを確認する

### 経費を申請する

1. カテゴリと金額を指定して経費を申請する
2. 自分の経費の一覧で状態を確認する

### 感謝を送り報酬と交換する

1. 同僚を指定して感謝メッセージを送る
2. 自分の残ポイントと受け取った感謝を確認する
3. 交換カタログから報酬を選び交換を申請する

### シフト交代を申請する

1. 自分のシフトを確認する
2. 交代相手と対象日を指定して交代を申請する

### 通知を確認する

1. 自分宛の通知と未読数を確認する
2. 通知を個別または一括で既読にする

## 上長や管理者導線

### 申請を承認または却下する

1. 自分宛の承認待ち一覧を確認する
2. 対象の申請の詳細を確認する
3. 申請を承認する or 却下する

### 経費を承認または却下する

1. 自分宛の経費の承認待ち一覧を確認する
2. 対象の経費の内容を確認する
3. 経費を承認する or 却下する

### 感謝ポイントの交換を承認または却下する

1. 交換申請の承認待ち一覧を確認する
2. 対象の交換申請を確認する
3. 交換を承認する or 却下する

### 組織の状態を把握する

1. ダッシュボードの集計を確認する
2. 必要に応じて社員を検索する

### ロールを作って権限を絞る

1. 権限カタログを確認する
2. 必要な権限だけを選んでロールを作成する
3. 対象のアカウントにロールを割り当てる
4. 対象者の画面とメニューが権限どおりに絞られる
