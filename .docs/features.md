# 機能一覧

業務機能は api が提供し、karte コマンドと web から実行する。機能の網羅的な定義はコード(api/src/interface と app.ts)を正とする。ここでは利用者視点の機能を概観する。

全機能は api が提供し、karte コマンドと web の両方から利用できる。給与・評価・シフト・研修・通知を含む主要ドメインは web 画面も実装済み。web 画面の一覧は [[sitemap|サイトマップ]]、主要導線は [[user-flows|ユーザーフロー]] を参照する。

## 認証

- メールアドレスとパスワードでログインし、トークンを取得する
- ログイン中の自分の情報を表示する

## 社員と組織

- 社員を検索する(キーワード、部署、在籍状況で絞り込み)
- 社員を登録、編集、削除する
- 組織ツリーやレポートライン、部署メンバーを確認する
- 部署を作成、編集、削除する

## 申請ワークフロー

- 申請テンプレートの一覧と詳細を確認する
- テンプレートを指定して申請を提出する
- 自分宛の承認待ち一覧と、自分が出した申請を確認する
- 申請を承認または却下する(コメント付き)

## 勤怠と休暇

- 出退勤を打刻し、自分の勤怠と月次サマリを確認する
- 休暇を申請し、残数を確認する
- 休暇を承認または却下する

## 経費

- 経費を申請し、自分の経費を確認する
- 自分宛の承認待ちを確認し、承認または却下する

## ナレッジ

- ナレッジを検索する(キーワード、カテゴリで絞り込み)
- ナレッジの詳細を確認する
- ナレッジを作成、編集、削除する

## 会議室と備品

- 会議室の空き状況を確認し、予約する
- 備品を登録し、貸出と返却を記録する

## スキルと目標

- スキルの一覧を確認し、自分のスキルを登録または更新する
- 目標を作成し、自己評価、上長評価、最終評価を登録する

## 1on1とアンケート

- 1on1の履歴を確認し、記録を作成する
- オープン中のアンケートに回答し、集計を確認する

## 感謝(サンクス)

- 同僚へ感謝メッセージを送る
- 自分の月次の贈与原資(残ポイント)と受け取った感謝を確認する
- 交換カタログの報酬一覧を確認し、ポイントと引き換えに交換を申請する
- 報酬カタログを登録、編集する(管理者)
- 交換申請の承認待ちを確認し、承認または却下する

## キャリア

- 自分のキャリアシートを確認し、更新する
- 社内公募の一覧を確認し、応募する

## オンボーディング

- オンボーディングのテンプレートを管理し、社員に割り当てる
- 自分のタスクを確認し、完了にする

## 給与

- 給与明細を発行し、自分の明細を確認する
- 給与改定を登録し、社員ごとの改定履歴を確認する

## 評価

- 評価サイクルを作成し、開始と締切を切り替える
- 評価フォームを提出し、結果を確認する

## シフト

- シフトパターンと割当を作成し、公開する
- シフト交代を申請し、承認する

## 研修

- 研修コースを作成し、一覧と詳細を確認する
- 研修に登録し、受講を完了にする

## 通知

- 自分宛の通知と未読数を確認する
- 通知を既読にする(個別、一括)

## 労務・ライフイベント手続き

事実の記録と申出のワークフローのみを扱い、給付額や税額の計算、法的判定は持たない。

- 出張を申請し、自分の申請を確認、編集、取り消す
- 貸与品のレンタルを予約し、自分の予約を確認、編集、取り消す
- 退職を申し出て、受付から書類交付までの状況を記録する
- ライフイベント(結婚、出産、転居、忌引、扶養変更など)を届け出る
- 産休、育休、介護休業を申し出て、期限を管理する
- 在職、就労、退職などの証明書発行を依頼する
- 年末調整の申告を提出し、提出状況を確認する
- 取引先の反社チェックを申請し、確認結果を記録する

## ダッシュボードとバッチ

- ダッシュボードの集計を表示する
- バッチの状況を表示する
