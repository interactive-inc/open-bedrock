# 機能一覧

業務機能は api が提供し、karte コマンドと web から実行する。機能の網羅的な定義はコード(api/src/interface と app.ts)を正とする。ここでは利用者視点の機能を概観する。

全機能は api が提供し、karte コマンドと web の両方から利用できる。研修(training)の web 画面は実装済みだが main への反映は PR #10 のマージ後に完了する。

## 認証

- メールアドレスとパスワードでログインし、トークンを取得する
- ログイン中の自分の情報を表示する

## 社員と組織

- 社員を検索する(キーワード、部署、在籍状況で絞り込み)
- 組織ツリーやレポートライン、部署メンバーを確認する

## 申請ワークフロー

- 申請テンプレートの一覧と詳細を確認する
- テンプレートを指定して申請を提出する
- 自分宛の承認待ち一覧と、自分が出した申請を確認する
- 申請を承認または却下する(コメント付き)

## 勤怠と休暇

- 出退勤を打刻し、自分の勤怠と月次サマリを確認する
- 休暇を申請し、残数を確認する
- 休暇を承認または却下する

## 経費

- 経費を申請し、自分の経費を確認する
- 自分宛の承認待ちを確認し、承認または却下する

## ナレッジ

- ナレッジを検索する(キーワード、カテゴリで絞り込み)
- ナレッジの詳細を確認する

## 会議室と備品

- 会議室の空き状況を確認し、予約する
- 備品を登録し、貸出と返却を記録する

## スキルと目標

- スキルの一覧を確認し、自分のスキルを登録または更新する
- 目標を作成し、自己評価、上長評価、最終評価を登録する

## 1on1とアンケート

- 1on1の履歴を確認し、記録を作成する
- オープン中のアンケートに回答し、集計を確認する

## キャリア

- 自分のキャリアシートを確認し、更新する
- 社内公募の一覧を確認し、応募する

## オンボーディング

- オンボーディングのテンプレートを管理し、社員に割り当てる
- 自分のタスクを確認し、完了にする

## 給与

- 給与明細を発行し、自分の明細を確認する
- 給与改定を登録し、社員ごとの改定履歴を確認する

## 評価

- 評価サイクルを作成し、開始と締切を切り替える
- 評価フォームを提出し、結果を確認する

## シフト

- シフトパターンと割当を作成し、公開する
- シフト交代を申請し、承認する

## 研修

- 研修コースを作成し、一覧と詳細を確認する
- 研修に登録し、受講を完了にする

## 通知

- 自分宛の通知と未読数を確認する
- 通知を既読にする(個別、一括)

## ダッシュボードとバッチ

- ダッシュボードの集計を表示する
- バッチの状況を表示する
