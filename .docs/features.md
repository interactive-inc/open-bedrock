# 機能一覧

ここに記載する機能は現行の TypeScript 版 CLI(talent コマンド)から実行できるものを基準とする。API サーバ(api)と web は現状スキャフォールド状態であり、業務機能は未実装。

## 認証

- メールアドレスとパスワードでログインし、トークンを取得する
- ログイン中の自分の情報を表示する
- 接続先サーバを切り替えられる
- ステータス: 利用可能

## フィーチャー確認

- サーバ側で有効になっている機能の一覧を表示する
- コア機能とオプション機能を区別して表示する
- ステータス: 利用可能

## 社員

- 社員を検索する(キーワード、部署、在籍状況で絞り込み)
- ステータス: 利用可能

## 申請ワークフロー

- 申請テンプレートの一覧と詳細を確認する
- テンプレートを指定して申請を提出する
- 自分宛の承認待ち一覧を確認する
- 自分が出した申請の一覧と詳細を確認する
- 申請を承認または却下する(コメント付き)
- ステータス: 利用可能

## ナレッジ

- ナレッジを検索する(キーワード、カテゴリで絞り込み)
- ナレッジの詳細を確認する
- ステータス: 利用可能

## 会議室

- 指定期間の会議室の空き状況を確認する(定員での絞り込み)
- 会議室を予約する
- ステータス: 利用可能

## スキル

- スキルの一覧を確認する(キーワード、カテゴリで絞り込み)
- 自分のスキルを確認する
- 自分のスキルを登録または更新する(レベル、年数、メモ)
- ステータス: 利用可能

## 目標管理

- 目標の一覧を確認する(期間、社員で絞り込み)
- 目標を作成する(期間、タイトル、KPI、ウェイト)
- 目標に対する評価を登録する(自己評価、上長評価、最終評価)
- ステータス: 利用可能

## 1on1

- 1on1の履歴を確認する
- 1on1の記録を作成する(トピック、上長メモ、ネクストアクション)
- ステータス: 利用可能

## アンケート

- オープン中のアンケートの一覧を確認する
- アンケートに回答する
- アンケートの集計結果を確認する
- ステータス: 利用可能

## キャリア

- 自分のキャリアシートを確認する
- キャリアシートを更新する
- 社内公募の一覧を確認する
- 社内公募に応募する
- ステータス: 利用可能(キャリアボードはβ表記)

## ダッシュボードとバッチ

- ダッシュボードの集計を表示する
- バッチの状況を表示する
- ステータス: 利用可能
