# 経費申請

最終更新: 2026-05-31

優先度: 中。お金領域の中核。台帳と申請基盤の後。

---

## 背景

お金領域(経費)の申請と精算状態を記録する。経費がメールや紙で回ると、申請者は今どの段階か分からず、承認者も滞留を把握できない。

解く課題: 社員が経費を申請して状態を追えない。上長は承認待ちを一覧で確認して承認できない。

依存: 申請者と承認者の特定に[[employee-directory|従業員台帳]]、申請の状態管理に[[approval-workflow|申請ワークフロー基盤]]を必須とする。

## 調査

- 既存コードは存在しない [^1]
- 経費は金額と費目と証憑の有無の記録に留め、税計算や仕訳には踏み込まない([[index|やらないこと]]) [^1]

## 対応案

- 最小の形(MVP): 経費の申請(金額・費目・日付)、自分の経費の状態確認、自分宛の承認待ちの確認と承認/却下を提供する。状態管理は[[approval-workflow|申請ワークフロー基盤]]に乗せる
- 受け入れ条件の骨子: 経費を申請すると申請中になり自分の経費一覧に出る / 承認者の承認待ちに出る / 承認すると承認済みに状態が遷移する / 金額と費目を記録として確認できる / 税計算や会計仕訳は行わない
- 案B(精算連携): 振込や会計システムとの連携を持つ。MVP では記録と承認に絞り、連携は境界の外として外部に委ねる
