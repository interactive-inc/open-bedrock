# 備品・貸与管理

最終更新: 2026-05-31

優先度: 中。物領域の中核。台帳と申請基盤の後。

---

## 背景

物領域(備品や貸与物)の在庫と貸出状況を記録する。誰が何を借りているかが分からないと、返却漏れや紛失が起き、棚卸しもできない。

解く課題: 運用担当が備品の在庫を把握できず、貸出と返却を記録できない。社員も自分が何を借りているか分からない。

依存: 借用者の特定に[[employee-directory|従業員台帳]]、貸与の申請を伴う運用にする場合は[[approval-workflow|申請ワークフロー基盤]]を使う。

## 調査

- 既存コードは存在しない [^1]
- 貸出は「物」と「借りた人」と「期間」の記録に集約できる。会計上の資産管理(減価償却など)には踏み込まない([[index|やらないこと]]) [^1]

## 対応案

- 最小の形(MVP): 備品の登録と一覧・在庫の確認、貸出と返却の記録、誰が何を借りているかの確認を提供する。貸与申請の承認は任意で[[approval-workflow|申請ワークフロー基盤]]に乗せる
- 受け入れ条件の骨子: 備品を登録すると一覧と在庫で確認できる / 貸出を記録すると在庫が減り借用者が記録される / 返却を記録すると在庫が戻る / 借用中の備品を借用者で絞り込める / 減価償却など会計計算は行わない
- 案B(申請必須): 貸出を必ず申請承認経由にする。MVP では直接記録を基本とし、申請は任意
