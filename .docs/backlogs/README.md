# バックログ

規範性: 非規範記録。採用済み roadmap 項目とその完了条件を保存する。

採用済みの roadmap 項目を一項目一ファイルで記録する。個別ファイルだけを roadmap 採用の正本とする。機能仕様、実装状態、リリース時期の正本にはしない。

[製品能力境界](../capability-map.md) の部分実装、台帳のみ、未実装は開発を約束しない。`api/src/schema.ts` に table が存在しても roadmap 採用とはみなさない。

ロードマップ項目には、解決する業務上の問題、対象利用者、採用理由、完了条件、依存関係を記載する。優先順位や時期を決定した場合は、根拠とともに同じ個別ファイルへ記載する。

現在、個別のロードマップ項目は登録されていない。給与明細、給与改定、年末調整は台帳スキーマだけが存在し、ロードマップには採用されていない。
