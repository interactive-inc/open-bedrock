# バックログ

このディレクトリは、採用したロードマップ項目を1項目1ファイルで記録する。個別ファイルが追加された項目だけをロードマップとして扱う。

[[capability-map|機能網羅表]] は現在の実装範囲と境界を示す。機能網羅表の部分実装、台帳のみ、未実装は、開発を約束する状態ではない。`api/src/schema.ts` にテーブルがあるだけでも、ロードマップへの採用とはみなさない。

ロードマップ項目には、解決する業務上の問題、対象利用者、採用理由、完了条件、依存関係を記載する。優先順位や時期を決定した場合は、根拠とともに同じ個別ファイルへ記載する。

現在、個別のロードマップ項目は登録されていない。給与明細、給与改定、年末調整は台帳スキーマだけが存在し、ロードマップには採用されていない。
