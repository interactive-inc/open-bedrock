# 定期健康診断の実施義務

規範性: 根拠記録。非実行の調査 snapshot。確認日は二〇二六年七月十六日、法域は日本。対象者、検査項目、期限、保存、事後措置の法的判断または機械実行の根拠に使用せず、利用時点の労働行政の公式情報と産業保健・労務の専門家を確認する。

事業者は、常時使用する労働者に医師による健康診断を行う。一般の定期健康診断は、原則として一年以内ごとに一回実施し、健康診断個人票を五年間保存する。

## 対象と頻度の分岐

一般の定期健康診断だけを全労働者へ一律に当てはめてはならない。深夜業などの特定業務に常時従事する労働者には、配置替え時および六か月以内ごとに一回の健康診断が原則として必要である。雇入れ時の健康診断、有害業務の特殊健康診断など、別の制度が適用される場合もある。

短時間・有期雇用労働者を含む対象判定は、契約期間、所定労働時間、常用性、従事業務などを踏まえて行う。単一の雇用区分だけで自動確定しない。

## 記録と事後措置

- 健康診断の種別、対象根拠、実施日、実施機関を記録する
- 健康情報そのものと、就業上必要な措置を知る権限を分離する
- 異常所見がある場合の医師等の意見と、就業場所変更や労働時間短縮などの措置を別の記録として残す
- 常時五十人以上を使用する事業場では、一般の定期健康診断結果報告の要否を確認する
- 保存期間、法域、根拠版および同意・閲覧履歴を記録する

本製品は対象候補の抽出、受診案内、実施事実、外部機関からの結果受領、権限制御および証跡を扱える。医学的判断、法的な対象確定および診断は外部へ委ねる。
