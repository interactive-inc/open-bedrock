[[nenji-yukyu-kyuka|年次有給休暇]]（年休）は、労働基準法39条が定める法定の休暇制度。雇入れから6か月継続勤務し、全労働日の8割以上出勤した労働者に対して、業種・雇用形態にかかわらず付与される。2019年4月からは、年10日以上付与される労働者に対する「年5日の取得義務」が使用者に課されている。

## 付与要件

雇入れの日から6か月間継続勤務し、その期間の全労働日の8割以上出勤した労働者に、10日の [[nenji-yukyu-kyuka|年次有給休暇]] を付与する。以後、継続勤務年数に応じて付与日数が加算される。

## 勤続年数別の法定付与日数（通常の労働者）

週所定労働日数5日以上、または週所定労働時間30時間以上の労働者は、継続勤務年数に応じて次の日数が付与される。

- 6か月: 10日
- 1年6か月: 11日
- 2年6か月: 12日
- 3年6か月: 14日
- 4年6か月: 16日
- 5年6か月: 18日
- 6年6か月以上: 20日

（直前1年間の出勤率が8割以上であることが各回の付与の条件）

## 比例付与（パートタイム労働者等）

週所定労働日数が4日以下、かつ週所定労働時間が30時間未満の労働者には、所定労働日数に応じて比例的に付与する。各行は「6か月 / 1年6か月 / 2年6か月 / 3年6か月 / 4年6か月 / 5年6か月 / 6年6か月以上」の順の付与日数。

- 週4日（年間169〜216日）: 7日 / 8日 / 9日 / 10日 / 12日 / 13日 / 15日
- 週3日（年間121〜168日）: 5日 / 6日 / 6日 / 8日 / 9日 / 10日 / 11日
- 週2日（年間73〜120日）: 3日 / 4日 / 4日 / 5日 / 6日 / 6日 / 7日
- 週1日（年間48〜72日）: 1日 / 2日 / 2日 / 2日 / 3日 / 3日 / 3日

## 年5日の取得義務

年10日以上の [[nenji-yukyu-kyuka|年次有給休暇]] が付与される労働者については、付与した日（基準日）から1年以内に、使用者が時季を指定して5日を確実に取得させなければならない。労働者が自ら請求・取得した日数や、計画的付与で取得した日数は、この5日から差し引く（それらが5日以上あれば使用者の時季指定は不要）。違反した場合は、対象労働者1人につき30万円以下の罰金の対象となりうる。

## その他

- 時効: 年休の請求権は2年で時効消滅する（付与年度に取得しきれなかった分は翌年度に繰り越せる）。
- 半日・時間単位: 時間単位年休は労使協定により年5日の範囲で導入可能。
