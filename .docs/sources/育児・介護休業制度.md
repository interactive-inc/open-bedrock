# 育児・介護休業制度

規範性: 根拠記録。非実行の調査 snapshot。確認日は二〇二六年七月十六日、法域は日本。対象、期間、申出、給付、期限、法的適用の判断または機械実行の根拠に使用せず、利用時点の労働行政の公式情報と労務専門家を確認する。

育児・介護休業法は、仕事と育児・介護の両立を支える休業、休暇、勤務上の措置、個別周知・意向確認などを定める。雇用保険の給付制度は関連するが、休業を取得できるかという判定と給付を受けられるかという判定は同一ではない。

## 育児に関する主な制度

- 育児休業は原則として一歳未満の子を養育する労働者が対象で、分割取得や一定の場合の延長がある
- 出生時育児休業は出生後八週間以内に通算四週間まで取得でき、二回まで分割できる
- 出生時育児休業中の就業には、労使協定だけでなく、労働者本人からの申出と個別合意など所定の手続が必要である
- 子の看護等休暇、所定外労働の制限、短時間勤務などは、子の年齢や雇用条件に応じて適用が分かれる
- 三歳から小学校就学前の子を養育する労働者について、事業主は法定の五つの選択肢から二つ以上の柔軟な働き方措置を用意し、個別周知と意向確認を行う
- 仕事と育児に関する個別の意向聴取と、その意向への配慮が必要となる場面がある

## 介護に関する主な制度

- 介護休業は対象家族一人につき通算九十三日まで、三回を上限に分割できる
- 介護休暇は対象家族の人数に応じた日数を時間単位でも取得できる
- 事業主には介護離職防止のための雇用環境整備が求められる
- 介護に直面した労働者への個別周知と意向確認、および介護に直面する前の早期情報提供が必要となる
- 介護を目的とするテレワークの導入は努力義務である

## 給付との分離

育児休業等給付には、育児休業給付、出生時育児休業給付に加え、二〇二五年四月から出生後休業支援給付と育児時短就業給付が含まれる。介護休業給付も別に存在する。支給要件、期間、額の判定と計算は外部へ委ねる。

本製品は家族関係の必要最小限の事実、申出、対象候補、会社の措置、合意、承認、外部申請、給付結果および証跡を記録できる。法的な取得可否、給付判定、金額計算および行政申請の正しさは外部の制度実行者または専門家に委ねる。
