# 源泉所得税の対象と税率

規範性: 根拠記録。非実行の調査 snapshot。確認日は二〇二六年七月十六日、法域は日本。対象判定、税率選択、税額計算、納付、申告または機械実行の根拠に使用せず、利用時点の国税当局の公式情報と税務専門家を確認する。

報酬・料金等の源泉徴収義務は、支払者、受取者、支払の性質および例外規定の組合せで決まる。すべての支払者またはすべての業務委託費に一律に生じるものではない。

## 判定に必要な観点

- 受取者が居住者、非居住者、内国法人または外国法人のいずれか
- 支払者が法人か個人か、個人なら給与等の支払者に該当するか
- 支払が給与、退職手当、報酬・料金、契約金または賞金のどれに該当するか
- 原稿料、講演料、士業報酬、外交員報酬など、法令上のどの区分に該当するか
- 支払額、控除額、段階税率、消費税額の区分表示など、その区分固有の計算条件
- 租税条約、免除証明その他の例外があるか

居住者へ国内で対象報酬を支払う者は、原則として所得税と復興特別所得税を源泉徴収する。ただし、支払者が個人で給与等の支払者でない場合や、常時二人以下の家事使用人だけに給与を支払う場合には、ホステス等への特定の支払を除く例外がある。内国法人への支払にも区分固有の例外がある。

## 税率を共通化しない理由

原稿料や講演料の一部では十・二一パーセントと二十・四二パーセントの段階税率が用いられるが、司法書士、外交員、ホステス、契約金、賞金などは控除方法や算定基礎が異なる。したがって、単一の「源泉税率」欄や共通計算式をドメインの真実として置かない。

本製品は支払事実、契約、受取者属性、証憑、外部計算への入力、外部結果、根拠版、人間の承認および納付結果の照合を記録できる。対象判定、税額計算、納付および申告は外部の税務サービスまたは専門家へ委ねる。
