# 労働時間と時間外労働協定の上限規制

規範性: 根拠記録。非実行の調査 snapshot。確認日は二〇二六年七月十六日、法域は日本。労働時間の適法性判断、警告、給与計算または機械実行の根拠に使用せず、利用時点の労働行政の公式情報と労務専門家を確認する。

労働基準法上の法定労働時間は、原則として休憩を除き一日八時間、一週四十時間である。法定時間外または法定休日に労働させるには、原則として時間外・休日労働に関する労使協定を締結し、所轄の労働基準監督署長へ届け出る必要がある。

## 一般則

一般の事業について、協定で定める時間外労働の限度は原則として月四十五時間、年三百六十時間である。臨時的な特別の事情に対応する特別条項にも、一般には次の限界がある。

- 時間外労働は年七百二十時間以内
- 時間外労働と休日労働の合計は月百時間未満
- 時間外労働と休日労働の合計は複数月平均で月八十時間以内
- 月四十五時間を超えられるのは年六回まで

これらの規定への違反は、適用条文と事実関係により、六月以下の拘禁刑または三十万円以下の罰金の対象となり得る。

## 適用の分岐

上の数値を全業務へ一律に適用してはならない。新技術・新商品・新役務の研究開発業務には、月百時間未満および複数月平均月八十時間以内の規制について法定の適用除外がある。また、建設事業の災害復旧・復興、自動車運転業務、医師などには業務固有の上限や特例がある。

したがって製品では、労働時間の事実、対象業務、適用法域、協定の版と有効期間、特別条項の発動事実、外部判定および承認記録を分離して保持する。法的な適用判定と給与計算は外部へ委ねる。
