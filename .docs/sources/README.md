# 外部制度の調査記録

規範性: 根拠記録。公式 source を確認した時点の調査結果を保存する。

公式 source を基にした確認時点の調査結果を保存する非実行領域とする。法令、標準、外部制度は更新されるため、本文を製品仕様、施行中の規程、適用判断、機械実行 rule に使用しない。

各 snapshot は可能な範囲で次を明記する。

- jurisdiction または発行主体
- as_of または reviewed_on
- 公式 source URL
- 対象範囲と要約者の解釈
- 更新が必要になる条件
- executable: false に相当する非実行資料であること

日付のない資料は未検証として扱う。法律、税、給与、会計、健康、安全に関する判断は、利用時点の公式情報と外部専門家の回答を [記録・時間・来歴モデル](../records-model.md) の ExternalAssessment として記録する。
