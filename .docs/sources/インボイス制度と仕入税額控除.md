# インボイス制度と仕入税額控除

規範性: 根拠記録。非実行の調査 snapshot。確認日は二〇二六年七月十六日、法域は日本。税務判断、税額計算、申告、仕訳または機械実行の根拠に使用せず、利用時点の国税当局の公式情報と税務専門家を確認する。

適格請求書等保存方式は、二〇二三年十月から始まった消費税の仕入税額控除の方式である。買い手が控除を受けるには、原則として適格請求書などと所定の帳簿を保存する。適格請求書を交付できるのは、登録を受けた適格請求書発行事業者に限られる。

## 記録すべき事実

本製品で保持し得るのは、税額の正解そのものではなく、外部判断を再現・照合するための事実である。

- 取引当事者と登録番号
- 取引日、取引内容、対価、適用税率の区分
- 受領した証憑、その版、取得元、取得日時
- 外部税務サービスまたは専門家へ渡した入力
- 外部から返された判定、計算結果、根拠版、証跡
- 人間が承認した処理指示と照合結果

## 経過措置

適格請求書発行事業者以外からの課税仕入れに関する控除可能割合は、令和八年度税制改正後、次のように段階的に縮小する。

- 二〇二三年十月から二〇二六年九月まで: 八割
- 二〇二六年十月から二〇二八年九月まで: 七割
- 二〇二八年十月から二〇三〇年九月まで: 五割
- 二〇三〇年十月から二〇三一年九月まで: 三割
- 二〇三一年十月以後: 控除なし

二〇二六年十月一日以後に開始する課税期間では、一の適格請求書発行事業者以外の者からの課税仕入れの合計額が年または事業年度で税込一億円を超える場合、その超過部分にこの経過措置を適用できない。課税期間、相手方の同一性、例外および証憑要件を含む適用判定は外部に委ねる。

## 製品境界

本製品は、請求書の収集、申請、承認、外部サービスへの引渡し、結果の記録、証憑との照合を扱える。一方、仕入税額控除の適用可否、税額計算、申告、納付および法的助言は実装しない。
