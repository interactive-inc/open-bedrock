# ノート

規範性: 非規範記録。一般的な業務背景と手続き例を保存する。

一般的な社内事務の背景と手続き例を保存する非規範領域とする。製品仕様、導入組織の規程、法的助言、自動判定 rule の根拠に使用しない。

handbook は入社、休暇、経費、出張、ライフイベント、育児・介護、年末調整、外部確認、証明書、退職などを説明する。内容は導入組織の規程、法域、雇用条件、外部専門判断によって変わる。

次の制約を適用する。

- 実装機能は [実装機能](../features.md) とコードを正本とする。
- 導入組織の規則は施行中の governance 文書だけを正本とする。
- 法令の数値や期限は利用時点の公式 source で再検証する。
- ノート本文を AI の自動承認、税計算、法的判断、支払実行へ使わない。
- 導入先固有の名称、個人情報、秘密を公開リポジトリへ追加しない。
