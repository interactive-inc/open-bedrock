# 証明書の発行依頼

在職証明書・就労証明書など、従業員が会社に発行を依頼する各種証明書の流れをまとめる。

## 目的

従業員は、転居・融資・保育所の利用・ビザ申請などの外部手続きで、会社が在籍や就労の事実を証明する書類を求められることがある。会社は本人の依頼に基づき、事実に即した証明書を発行する。発行窓口と様式を整えることで、正確かつ迅速に対応する。

## 主な証明書の種類

- 在職証明書: 現に在籍していることを証明する
- 就労証明書: 勤務日数・勤務時間・雇用形態などを示す（保育所の利用申請などで使う）
- 退職証明書: 退職の事実や在職期間を証明する（[[退職の手続き|退職]] 時に交付）
- 収入に関する証明: 給与の支払い実績などを示す

提出先が指定の様式を求める場合は、その様式に会社が記入して発行する。

## 流れ

1. 本人が用途・提出先・必要事項・希望様式を指定して発行依頼する
2. 担当部門が在籍・就労・給与の事実を確認する
3. 証明書を作成し、社印などを付して発行する
4. 本人へ交付する（紙または電子）

申請→事実確認→作成→交付という順で進める。記載内容は人事・勤怠・給与の記録と突き合わせ、事実と相違ないことを確認してから発行する。

## 記載内容の考え方

証明書は事実の証明であり、用途に必要な範囲で記載する。提出先が求めていない個人情報は記載しない。記載項目は提出先の様式や用途によって変わるため、依頼時に必要事項を確認する。

## 提出期限の考え方

外部手続きには提出先が定める締切があるため、本人は余裕をもって依頼する。会社側は標準的な発行リードタイム（受付から交付までの目安日数）を定めておくと、期限超過を防げる。

## 関連する手続き

退職に伴う証明（退職証明書）は [[退職の手続き|退職の手続き]] の交付物として扱う。在職・就労の証明は人事・勤怠の記録を参照して作成する。
