# 産休・育休と介護

規範性: 非規範記録。種別は一般例。導入組織の規程、法的判断、給付計算、実装済み機能の正本として使用しない。

出産・育児・家族の介護に伴う長期の休業について、期限・申請・社会保険の取り扱いをまとめる。

## 目的

これらの休業は、従業員が出産・育児・介護のために一定期間仕事を離れても雇用が守られ、生活が支えられるようにする制度である。会社は申請を受け付けて休業期間を管理し、社会保険料の免除や復職の手続きを行う。給付金そのものは公的機関から支給されるが、会社が申請を取り次ぐ。

## 産前産後休業

出産予定日を基準に産前の一定期間と産後の一定期間取得できる休業。産後の一定期間は原則として就業させてはならない。本人の請求と医師の証明をもとに期間を確定する。

## 育児休業

[[ikuji-kyugyo|育児休業]] は子が一定年齢に達するまで取得できる休業で、保育所に入れないなど事情があれば延長できる。男女とも取得でき、分割して取得する仕組みや、出生直後の一定期間に取得する枠も設けられている。申請は原則として開始予定日の所定期間前までに行う。

## 介護休業

[[kaigo-kyugyo|介護休業]] は要介護状態の対象家族を介護するために取得できる休業。対象家族1人につき通算の上限日数が定められ、複数回に分けて取得できる。短期の対応は [[kaigo-kyuka|介護休暇]] を、長期の対応は介護休業を使い分ける。

## 申請の流れ

1. 本人が休業の種類・開始予定日・期間を申請する
2. 会社が期間と要件を確認する
3. 社会保険料免除・給付金の申請を取り次ぐ
4. 復職予定日を管理し、復職時の手続きを行う

## 社会保険料の免除

産前産後休業・育児休業の期間は、申請により [[shakai-hoken|社会保険]] 料（健康保険・厚生年金）の本人・会社負担が免除される。免除を受けても被保険者資格は継続する。

## 給付金（一般論）

休業中の所得を補うため、雇用保険や健康保険から給付が行われる仕組みがある（育児・出産・介護に関する給付）。支給額や要件は公的制度で定められ、会社は申請手続きを支援する立場にある。具体的な金額計算や判定は外部の公的機関に委ねる。

## 復職・短時間勤務

復職時は休業前の手続きの巻き戻し（社会保険料免除の終了など）を行う。育児期には所定労働時間を短縮する短時間勤務や所定外労働の制限を選べる制度があり、本人の申出に応じて運用する。

## 期限の考え方

各休業の申請には開始予定日からさかのぼった申出期限がある。社会保険料免除と給付金の申請は休業開始後すみやかに行う。
