# 退職の手続き

規範性: 非規範記録。種別は一般例。導入組織の規程、法的判断、税計算、実装済み機能の正本として使用しない。

従業員が退職するときに会社が行う、申出の受付から書類交付までの一連の事務手続きをまとめる。

## 目的

退職は雇用契約の終了であり、未払賃金の精算、社会保険・税の資格処理、会社資産の回収、本人が次の手続きで使う公的書類の交付までを漏れなく行う必要がある。本人・会社双方の権利義務を確定させ、後日のトラブルを防ぐことが目的になる。

## 退職申出のタイミング

民法上は退職の意思表示から原則2週間で雇用契約を終了できるが、就業規則で「1〜2か月前まで」と申出期限を定める会社が多い。引き継ぎ期間や [[nenji-yukyu-kyuka|年次有給休暇]] の消化を見込み、早めの申出が望ましい。退職日は最終出社日とは別に定めることが多く、有給消化日を挟んで退職日が後ろにずれる。

## 流れ

1. 本人が退職を申し出る（届出フォームの提出）
2. 退職届の提出と受理、退職日の確定
3. 引き継ぎ・[[nenji-yukyu-kyuka|年次有給休暇]] 消化の計画
4. 秘密保持・競業に関する誓約の確認
5. 備品・貸与物の返却と各種アカウントの停止
6. 社会保険・[[gensen-shotokuzei|源泉所得税]]・住民税の精算
7. 公的書類の交付

申請→チェックリストによる返却・精算確認→書類交付という順で進めると抜けが起きにくい。

## 必要書類・交付物

会社が回収するもの: 退職届、貸与品（PC・入館証・名刺・健康保険証など）。会社が交付するもの: 源泉徴収票、雇用保険の離職票、健康保険の資格喪失証明書、必要に応じて退職証明書。

## 精算の考え方

最終給与で未消化分や立替えの [[keihi-seisan|経費精算]] を清算する。社会保険は資格喪失日（退職日の翌日）を基準に保険料の最終月を判定する。住民税は退職時期により一括徴収か普通徴収への切替を選ぶ。退職金がある場合は別途、退職所得としての処理を行う。

## 期限の考え方

離職票は退職後すみやかに発行する（本人の失業給付手続きに必要）。源泉徴収票は退職後1か月以内が目安。社会保険の資格喪失届は退職日の翌日から所定日数内に行う。

## 関連する制度

[[shakai-hoken|社会保険]] の資格喪失、[[fuyo|扶養]] から外れる家族の手続き、退職後の住民税・所得税の取り扱いが関係する。退職後に転職しない期間がある場合は本人が健康保険の任意継続や国民健康保険を選ぶことになる。
