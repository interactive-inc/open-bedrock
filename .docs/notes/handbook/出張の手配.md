# 出張の手配

業務で遠方へ出向く出張について、定義・旅費・事前承認・手配の流れをまとめる。

## 目的

出張は通常の勤務地を離れて業務を行うことで、交通費・宿泊費・日当などの費用が発生する。費用の負担範囲と手配方法をあらかじめ定め、事前承認を経て手配し、後で精算することで、過不足のない費用処理と公平な運用を行う。

## 出張の定義

何を出張とみなすかは会社が規程で定める。勤務地からの距離や移動・拘束に要する時間を基準に、近距離の外出（直行直帰や近隣訪問）と出張を区別するのが一般的。宿泊を伴うか否かで日帰り出張と宿泊出張を分けることも多い。

## 旅費の構成

[[shuccho-ryohi|出張旅費]] は主に次の要素からなる。

- 交通費: 実費精算が基本。経路や等級の基準を定める
- 宿泊費: 1泊あたりの上限額を定め、その範囲で実費または定額を支給する
- 日当: 出張中の細かな諸雑費に充てる定額の手当

支給基準は役職や出張先（国内・海外）で差を設けることがある。

## 事前稟議

一定規模以上の出張や費用は、出発前に [[ringi|稟議]] で目的・行先・概算費用・期間を申請して承認を得る。事前承認により、出張の必要性と予算を組織として確認する。

## 手配の方法

手配には会社が代行する方式と、本人が立て替える方式がある。会社代行（手配窓口や法人契約での予約）では本人の立替が発生せず請求が会社へ直接届く。立替方式では本人が支払い、後で [[keihi-seisan|経費精算]] で払い戻す。どちらを使うかは費目や金額で使い分ける。

## 適格請求書の注意

交通機関・宿泊施設の領収書は、消費税の [[shiire-zeigaku-kojo|仕入税額控除]] のために [[invoice-seido|インボイス制度]] に対応した [[tekikaku-seikyusho|適格請求書]] であることを確認する。一部の公共交通には特例があるため、費目ごとに保存要件を確認する。受領した証憑は [[denshi-chobo-hozonho|電子帳簿保存法]] に沿って保存する。

## 流れ

1. 出張計画を立て、必要に応じて [[ringi|稟議]] で事前承認を得る
2. 交通・宿泊を手配する（会社代行または立替）
3. 出張を実施し、領収書・証憑を保存する
4. 帰着後に [[keihi-seisan|経費精算]] で実費を精算し、日当を支給する

## 期限の考え方

事前承認は出発前に完了させる。精算は帰着後、月締めの申請期限までに行う。
