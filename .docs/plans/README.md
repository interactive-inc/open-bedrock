# 実装計画

規範性: 非規範記録。作成時点の実装案と検証案を保存する。

作成時点の設計案、実装順序、検証項目を保存する非規範領域とする。計画は製品仕様、現行 route、実装状態、完了証明の根拠に使用しない。

- 現在の挙動はコード、migration、test を正とする。
- 将来も守る不変条件は本 directory ではなく正本モデルへ移す。
- checklist が残っていても未実装とは限らず、完了していても実装済みとは限らない。
- 古い file path、command、監査所見は現在のコードで再検証する。
- 新しい計画は対象、前提 commit、作成日、置換先を明記する。
