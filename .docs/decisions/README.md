# 判断履歴

規範性: 根拠記録。設計判断の理由、状態、置換関係を保存する。

設計判断の理由、状態、置換関係を一判断一ファイルで記録する。decision は判断時点の履歴であり、現在の製品仕様ではない。現在の規範は decision が指定する正本文書に置く。

- `accepted`: 現在採用している判断
- `superseded`: 後続 decision に置き換えられた判断
- `historical`: 移行理由を残すための履歴

decision 番号は変更しない。判断の変更は過去を上書きせず、後続 decision の `supersedes` で表す。`accepted` だけを理由の参照に使用し、実装済みかどうかはコードと test で判定する。
