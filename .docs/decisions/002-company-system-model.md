# 会社システムを三層モデルで表現する

## 状況

採用済み。

open-karte は、従業員台帳を土台に、「人・時間・物・お金・成長」をめぐる社内手続きを束ねる。この五軸はプロダクトの射程を説明しやすい一方、出張、備品貸出、研修のように複数軸へ同時に属する手続きを排他的に分類できない。

現行の機能区分には、認証、組織、申請ワークフロー、ナレッジ、通知、監査など、五軸へ自然に収まらない横断機能もある。機能区分をそのまま会社モデルにすると、共通する主体、期間、資源、判断、証拠、認可を領域ごとに再定義することになる。

## 判断

会社システムの目標モデルを、業務能力、共通意味モデル、横断統制の三層で表現する。詳細な概念、関係、不変条件、新領域の追加契約は [[company-model|社内事務のために会社をどう表現するか]] を正とする。

「人・時間・物・お金・成長」は非排他的な検索タグとして残す。タグは能力、手続き、画面、コマンド、文書へ複数付与できるが、データ所有、集約境界、認可、保存期間を決めない。

本判断は目標モデルを定めるものであり、既存スキーマの一括統合や、共通基盤への即時移行を決定しない。既存領域は機能変更に合わせて段階的に適合させる。

## 採用した構造

業務能力は、会社が何を継続的にできる必要があるかを表す。組織図、手順、画面、実装から独立させ、能力と実現手続きを分ける。

共通意味モデルは、主体、組織、所属、手続き、ケース、判断、時間、資源、価値、文書、来歴、外部参照の共通語彙を定める。各領域はこれらを組み合わせ、領域固有の意味と不変条件だけを追加する。

横断統制は、認証、認可、職務分離、監査、来歴、記録管理、機密区分、外部連携、冪等性をすべての領域へ適用する。業務状態は各領域が所有し、通知や監査ログを業務状態の正にしない。

## 検討した代替案

### 五軸を排他的な最上位領域にする

却下した。一つの手続きが複数軸を含み、認証、組織、知識、認可、監査の置き場所も定まらない。分類を守るために同じ事実を複製するか、意味の違う概念を同じ領域へ集める結果になる。

### 現行の機能区分を会社モデルにする

却下した。機能区分は利用者の導線と実装状況を説明するには適するが、組織改編、画面変更、機能統合で変わりやすい。手続き、承認、期間、文書、認可の再利用契約も示せない。

### すべてを汎用エンティティと任意属性で表す

却下した。新領域の追加は速く見えるが、型、参照、状態遷移、一意性、認可、履歴の不変条件が実行時の任意設定へ移る。社内事務の事実と証跡に必要な整合性をレビューしにくい。

### 三層モデルを採用する

採用した。能力の網羅性、領域横断の意味、認可と証跡を別の設計質問として検証できる。各領域の自律性を保ちながら、共通語彙と追加契約を共有できる。

## 理由

- 能力と実装を分けると、組織図や画面が変わっても会社が必要とする責務を追跡できる
- 共通意味モデルを置くと、人、期間、資源、判断、証拠、外部参照を領域間で同じ意味に保てる
- 横断統制を独立させると、所有者照合、職務分離、代理、一覧、集計、監査を領域ごとに欠落させにくい
- 五軸をタグへ下げると、プロダクトの説明力を残しながら複合手続きを表現できる
- 領域固有モデルを認めると、巨大な汎用スキーマを避け、型と不変条件をコードとデータベースで検証できる

## 社内事務の境界

三層モデルは、会社の全活動を open-karte に取り込む決定ではない。対象は社内事務の事実、関係、申請、承認、割当、記録、検索であり、給与、税務、会計、労務の重い計算と法的判定は外部へ委ねる。顧客管理、営業、販売、製品開発、製造、物流、顧客サポートなどのフロントオフィス実行系も対象外とする。

外部結果を記録するときは、入力、対象、基準時点、出所、版、取得時刻を保持する。記録した結果と、open-karte 自身が算出または判定した結果を混同しない。

## 結果

- 新領域は、能力、共通概念、横断統制への写像を実装前に記述する
- 五軸は複数付与できる検索タグとなり、排他的なディレクトリ構成や認可境界には使わない
- 公開済み手続き、判断、来歴、外部結果は版と履歴を重視する
- 既存領域の物理統合は要求せず、変更時に意味と不変条件を段階的に揃える
- 標準は語彙と設計観点の参照に使い、製品が各標準へ直接準拠するとは主張しない
- 新しい共通概念には学習コストが生じるため、概念追加の理由と再利用先をレビュー対象にする

## 参照した標準

組織、来歴、認可、手続き、記録、業務分類の観点は [[企業モデルと認可の参照標準]] を参照した。標準の概念をそのままデータベースへ複製せず、open-karte の対象範囲と実装制約に合わせて採用する。
